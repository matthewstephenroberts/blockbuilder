# GitHub Pages — BlockBuilder

This folder is the GitHub Pages site for the BlockBuilder project.

## Structure

```
pages/
├── index.html      # Landing page with a link into the app
├── .nojekyll       # Tells GitHub Pages not to run Jekyll processing
├── app/            # Built web app (auto-generated — don't edit directly)
└── README.md       # This file
```

## Building and deploying

```bash
./scripts/build-pages.sh
git add pages/
git commit -m "Build: web app for GitHub Pages"
git push
```

## GitHub Pages configuration

Repository → Settings → Pages:
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/pages`

## Notes

- `.nojekyll` is required — without it GitHub Pages' Jekyll processing can mangle the build's
  `_`-prefixed asset filenames.
- `pages/app/` is regenerated by `build-pages.sh` on every run; build artifacts are committed to
  git (same approach as this project's Electron desktop build) so the Pages site doesn't need a
  separate CI build step.
